# ToyDB — Advanced Database Systems Assignment

This repository contains the implementation of an assignment for the **Advanced Database Systems** course at **IIT Bombay (IITB)**.

The assignment involves implementing and testing key components of a toy database system, including the record layer, slotted-page storage, CSV data loading, B+ tree indexing, and sequential/index-based data retrieval.

## Team

* **Ankit Banerjee**

## Branches

The repository contains two independent implementations of the same database system:

* **`dev` / `toydb-test`** — implementation by **Abhik Shil**
* **`Antro`** — implementation by **Ankit Banerjee**

Both branches implement the requirements of the same assignment independently. The implementations may differ in their internal design and coding approach while providing the same overall functionality.

The **`main`** branch serves as the primary repository branch containing the project documentation and common project structure.
